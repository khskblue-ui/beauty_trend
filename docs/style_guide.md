# 리포트 문체 가이드

독자는 향료 회사 영업 담당자와 그 상사입니다. 국내 업계지 기자가 쓴 짧은 보도 문장처럼 읽혀야 합니다.
규칙의 기계용 정본은 `config/style.yaml`입니다. 이 문서는 사람이 읽는 설명입니다.

## 매달 자동으로 하는 일

1. write 단계: 프롬프트에 `config/style.yaml`의 규칙이 들어갑니다.
2. style 단계(`trend/style.py`): 생성된 문장을 규칙으로 검사하고, 걸린 문장만 write 모델이 고쳐 씁니다. 고칠 때 출처(doc_ids)와 근거 인용(quote)은 바꾸지 않습니다.
3. verify 단계: 고친 문장도 처음부터 다시 검증합니다. 사실이 달라지면 빠집니다.
4. 기록: 고친 전후는 `reports/<월>/<실행>/style_log.json`에 남습니다. 고친 뒤에도 남은 경고는 `run.json`과 드라이런·보류 메일의 "[유지보수자용] 문체 점검"에 나옵니다.

## 유지보수자가 하는 일(매월 25일 드라이런 메일을 받았을 때)

- "남은 경고"가 있으면 문장을 읽어 보고, 어색하면 `config/style.yaml`의 `sentence_rules`에 패턴을 추가합니다. 다음 달부터 자동으로 반영됩니다.
- 경고에 걸리지 않았는데 어색한 표현이 보여도 같은 방법으로 규칙을 추가합니다.
- 템플릿 문구(제목, 설명, 표 머리글)를 고칠 때는 `pytest`를 돌립니다. `tests/test_style.py`가 개발 용어와 번역체를 잡아냅니다.

## plain-korean-writing 스킬 규칙(2026-10-15부터)

유지보수자가 지정한 `plain-korean-writing` 스킬의 규칙을 함께 따릅니다. 기계로 막을 수 있는 꼴은 `config/style.yaml`에 옮겨 두었습니다.

- 줄표(—)와 가운뎃점(·)을 쓰지 않습니다. 나열은 쉼표나 '와/과'로 잇습니다. CSS로 그리는 글자(`content:`)도 같습니다.
- 날수를 한글 고유어로 쓰지 않습니다.
- 글에서만 쓰는 말과 영어를 옮긴 은유를 쓰지 않습니다. 사물에 사람의 동작을 붙이지 않습니다.
- 처음 나오는 회사, 브랜드, 제품은 그 자리에서 이름을 댑니다.
- 규칙 설명(`hint`)에는 예시 문장을 넣지 않습니다. 프롬프트에 들어가 모델이 그 문장을 따라 씁니다.
- 결과물을 내기 전에 독자가 보는 글 전체를 스킬의 `check_plain_korean.py`로 검사해 거부를 0으로 만듭니다.

## 원칙

| 원칙 | 하지 말 것 | 이렇게 |
|---|---|---|
| 사실만 쓴다 | 기대된다, 주목된다, 눈길을 끈다, 것으로 보인다 | (빼고 사실만) |
| 홍보 문구를 옮기지 않는다 | 독자 개발한 혁신 복합 원료, 피부 본연의 건강함에 집중한 | 복합 원료로 만든 기능성 제품을 냈다 |
| 구체적인 행동으로 쓴다 | 시장 진출을 가속화했다, 공략을 본격화했다, 입지를 강화했다 | 투자를 받았다, 매장을 열었다, 인수를 마쳤다 |
| 직역하지 않는다 | 규제 대화를 강화했다, 리더십 회의를 소집했다, 자사의 | 규제를 두고 협의를 이어 갔다, 경영진 회의를 열었다 |
| 조사를 겹치지 않는다 | 천연 원료 분야에서의 입지 | 천연 원료 사업 |
| '~을 통해'를 줄인다 | 전략적 투자를 통해 역량을 확대했다 | 투자해 생산 능력을 늘렸다 |
| 짧게 잇는다 | 유치하여, A와 B 및 C | 유치해, A, B, C |
| 겹치는 말을 줄인다 | 최종 완료, 양성하여 배출 | 마쳤다, 길러 냈다 |
| 숫자는 쓰지 않는다 | (LLM 문장 속 금액·비율) | 숫자는 프로그램이 계산해 표·차트에만 |

## 템플릿 고정 문구

독자에게 개발 용어를 보이지 않습니다.

| 쓰지 말 것 | 대신 |
|---|---|
| 검증을 통과한 문장 | 출처로 확인된 문장 |
| 근거 사건, 기사 묶음, 클러스터 | 관련 보도(같은 내용의 기사는 한 건으로 셈) |
| 헤드라인급 근거 | 기사 제목·요약 기준 |
| 품질 게이트, 드라이런 | 기준, 시험본 |
| 데이터 커버리지 | 수집 현황 |
| n=33 | 33개 제품 |
| 블로터 스트립, 시료, 검출기, 질량 스펙트럼 | 향 노트별 제품 수, 향 노트를 밝힌 제품, 검색량 추이 |
| 신제품 트래커, 향 노트 픽, 고객사 워치 | 신제품 출시, 이달의 향 노트, 고객사 동향 |
